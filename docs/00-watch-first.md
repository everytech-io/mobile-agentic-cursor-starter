# Watch first (before exercises)

Start with **two official Cursor lessons** (~15–20 min total). They give you the mental model this repo builds on.

## 1. How agents work

**[Cursor Learn — Agents](https://cursor.com/learn/agents)**

Covers tokens, tools, and why Agent mode is different from autocomplete. Read/watch before touching the sample app.

## 2. How to work with agents day to day

**[Cursor Learn — Working with agents](https://cursor.com/learn/working-with-agents)**

Covers effective prompts, context, and the Plan → Act → Verify loop.
